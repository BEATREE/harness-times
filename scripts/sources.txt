# Harness Times 「关联网站」清单
# 每行一个 URL，# 开头为注释。
# 用途：跑 `node scripts/check-links.mjs --file=scripts/sources.txt` 验活，
#       再把确认可用的写进 src/pages/about.astro 的「关联网站」区。

# 备注（2026-09 校验时的情况）：
#   · openai.com 系域名会对非浏览器 UA 返回 403，属正常反爬，链接本身有效。
#   · 少数域名在受限网络下会直接 fetch failed，不代表站点已下线。
#   · GitHub 上被重命名过的仓库会 301 到新地址，脚本已跟随重定向。
